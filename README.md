Emberline is a tactical round-based shooter in a desert yard, built with three.js. Two squads of five fight over a bomb: plant it at Site A or B — or eliminate the VEX squad. Earn money each round and spend it between rounds on rifles, SMGs, a scoped sniper, grenades and Kevlar. First to 8 rounds takes the match.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. No build step, no network — the game runs entirely from the files in `game/`.

## Controls

- **W A S D** — move, **Mouse** — look, **Click** — fire
- **Right-click** — sniper scope
- **R** — reload, **Ctrl** — crouch, **Space** — jump
- **E** — plant the bomb (hold, inside a site)
- **B** — buy menu, **1–4** — switch weapon, **G** — throw grenade
